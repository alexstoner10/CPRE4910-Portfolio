Copy the portfolio PDFs directly into this folder with these exact names:

- resume.pdf
- general-education-reflection.pdf
- cumulative-reflection.pdf
- ethics-paper.pdf
- senior-design.pdf

The site embeds each PDF in an in-page reader and also provides a download link.

For example, the resume must be saved as:

`CPRE4910-Portfolio/public/documents/resume.pdf`

Do not put the files in `src/` or in the repository root. After adding the files, run `npm run dev` and open the Resume or Reflections page to check the embedded readers.
